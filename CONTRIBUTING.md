# Как предложить изменение

Repository и документация публичны. Любой разработчик может сделать fork,
создать branch и открыть pull request.

Не добавляйте `BroadExtensions`, Adapty/StoreKit imports, app-owned IDs/secrets,
real financial operations и test targets. Обновите docs/gallery/contracts/API
report/changelog, выполните `bash Scripts/module_gate.sh` и объясните в PR, что
изменилось и почему.
